# Source Repository Rules

- These repositories are decomposition inputs and are read-only by default.
- Confirm the matching workspace authorization before inspecting source.
- Do not install, build, run, migrate, write data, use the network, or contact external services unless the exact capability is enabled.
- Keep all notes and generated documentation outside `sources/`.
- Treat `.env`, databases, user files, generated output, caches, and dependencies as excluded unless the user explicitly authorizes a narrow read.
