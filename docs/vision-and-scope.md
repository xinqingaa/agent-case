# 愿景与范围

版本：0.2.0
状态：试行

## 愿景

把一个陌生代码仓库转化为一套可验证、可学习、可复习的项目认知系统，使学习者能够从产品价值进入实现细节，并通过证据、运行观察和练习验证自己的理解。

## 目标读者

- 希望系统学习完整项目的初学者和开发者。
- 需要为项目维护、交接或入职建立认知地图的人。
- 希望基于真实实现准备项目表达和技术面试的人。
- 负责维护拆解规范、模板和 Agent 工作流的人。

## 成功结果

完成一个项目后，学习者应能：

1. 解释项目解决的问题、目标用户和主要产品链路。
2. 在明确环境中运行或准确说明为什么暂时无法运行。
3. 建立系统边界、模块依赖、数据状态和运行时流程。
4. 按关键链路阅读代码，而不是逐文件浏览。
5. 解释正常、失败、重试、降级和数据副作用。
6. 完成带有成功判定方法的学习练习。
7. 区分项目事实、个人贡献、推断和未知。

## 非目标

- 不覆盖每个文件、类和函数。
- 不自动重构、修复或现代化被分析项目。
- 不把旧文档、命名和面试稿直接当成实现事实。
- 不用篇幅、文件数量或图表数量代替学习效果。
- 不在未授权时读取、运行或修改源码。
- 不提前建设尚无重复需求支撑的复杂平台或 MCP。
