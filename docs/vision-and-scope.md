# 愿景与范围

版本：0.3.0
状态：0.2 已冻结

## 愿景

把一个陌生代码仓库转化为一套可验证、可学习、可复习的项目认知系统。读者从产品价值和业务思路进入系统协作，并能通过运行观察和可判定任务验证理解。拆解方法论留在 Agent 后台，不成为读者的第二套课。

## 目标读者

默认读者是有工程背景、但不是该仓库作者的人：

- 前端深厚：不需要实现教程。
- 后端与 AI（LLM、RAG、编排等）为概念级：只在本项目用到时解释。
- 关心前后端如何协作、前端参与到哪一层、系统按什么逻辑运转、如何做 AI-native 调试。
- 维护拆解规范、模板和 Agent 工作流的人（读规范，不把规范抄进学习文档）。

「零基础」只表示「不是这个项目的作者」。

## 成功结果

完成一个项目后，读者应能：

1. 解释项目解决的问题、目标用户和主要产品链路。
2. 在明确环境中运行，或准确说明为什么暂时无法运行。
3. 建立系统边界、模块依赖、数据状态和运行时协作。
4. 讲清一条价值链路如何端到端协作，而不是去精读函数。
5. 说明关键业务如何判断、前端参与到哪一层、失败时怎么查。
6. 完成偏向定位、协作和调试的可判定任务。
7. 区分项目事实、个人贡献、推断和未知。

## 非目标

- 不覆盖每个文件、类和函数。
- 不以函数精读或纯前端实现知识作为学习主线。
- 不要求读者学习阶段码、证据字母表或授权矩阵。
- 不自动重构、修复或现代化被分析项目。
- 不把旧文档、命名和面试稿直接当成实现事实。
- 不用篇幅、文件数量或图表数量代替学习效果。
- 不在未授权时读取、运行或修改源码。
- 不提前建设尚无重复需求支撑的复杂平台或 MCP。
