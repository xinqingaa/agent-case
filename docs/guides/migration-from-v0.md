# 从 v0 目录迁移

2026-08-19，仓库从单一 `decomposition/` 容器迁移为仓库级拆解系统。

| 旧位置 | 当前位置 |
|---|---|
| `decomposition/SPEC.md` | `docs/specifications/` |
| `decomposition/PLAN.md` | `docs/roadmap.md` |
| `decomposition/templates/` | `templates/project-decomposition/` |
| `decomposition/skills/` | `.agents/skills/` |
| `decomposition/projects/` | `workspaces/` 或 `archive/pilots/` |
| `code/` | `sources/` |
| 旧 `docs/`、`assets/` | `archive/legacy-v0/` |

旧试点仍保留采集时路径和结论，不代表当前源码位置或当前规范。新工作区必须使用新路径和 0.2 版授权模型。
