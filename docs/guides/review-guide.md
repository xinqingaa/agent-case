# 评审指南

## 第一轮：范围与权限

确认调查没有超过能力矩阵，敏感目录和禁止操作得到遵守，源码保持只读。

## 第二轮：证据与矛盾

抽查产品、架构、核心链路、风险和指标结论，验证证据 ID、路径、符号和状态标记。发现文档与实现冲突时记录双方，不静默修正。

## 第三轮：跨文档一致性

比较产品步骤、架构图、核心链路、数据状态、测试覆盖、练习和面试声明。重点检查同一入口、端口、组件或状态是否出现互相矛盾的描述。

## 第四轮：学习体验

让缺少背景的读者按学习导航完成一次定位或解释任务。若读者只能复述文档而不能定位入口、画出链路或判断练习成功，则学习设计尚未通过。

## 最终检查

先运行机械校验，再填写人工结论和豁免。机械通过不能直接等同 G6 通过。
