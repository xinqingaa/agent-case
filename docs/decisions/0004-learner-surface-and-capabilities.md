# ADR-0004：学习面减负、默认读者画像，以及用业务思路替换代码精读

状态：接受
日期：2026-08-19

## 背景

0.2 初稿把阶段码、证据标记和函数精读写进了读者要看的详细文档。默认读者也被写成编程小白。实际使用者是有工程背景、但不是该仓库作者的人：前端深厚，后端和 AI 为概念级，关心协作、业务能力和思路，而不是再学一套拆解方法论或精读函数。

## 决定

1. 保留 P0–P6、授权矩阵和证据模型，作为 Agent 与脚本的后台约束。
2. 学习文档用白话和路径定位；不要求读者认识阶段码或证据字母表。用户只需确认可否读源码、可否运行、可否联网。
3. 默认读者画像写入文档契约：项目陌生不等于技术小白；省略纯前端实现教程；深度按需。
4. 将 `09-key-code-deep-dives.md` 替换为 `09-capabilities-and-thinking.md`。Agent 仍可读源码核实，正文不面向函数精读。

## 后果

- 平铺学习文件 与 `EVIDENCE.md` / `ACCEPTANCE.md` 分工更清楚。
- 详细版仍是学习事实源，但引用方式改为路径、模块和命令；证据 ID 留在台账。
- 模板、Skill、初始化脚本和校验清单必须同步改认新的 `09` 文件名。
- 归档试点仍保留旧的代码精读篇，不作为当前契约。
