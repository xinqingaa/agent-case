# ADR-0001：仓库级能力取代 decomposition 容器

状态：接受
日期：2026-08-19

## 背景

早期规范、模板、Skill、脚本和项目产物全部位于 `decomposition/`，而根目录的 `docs/` 和 `assets/` 保存旧项目拆解。这使仓库入口、当前事实源、执行能力和历史资料的语义混乱。

## 决定

移除 `decomposition/` 中间层。当前规范进入 `docs/`，Skill 进入 `.agents/skills/`，模板、Schema、脚本、测试、源码输入、工作区和归档成为一级目录。

## 后果

- 根目录能够表达项目本身的架构。
- Codex 可以按标准位置发现仓库 Skill。
- 旧拆解不再占用 `docs/` 的当前事实源语义。
- 所有活跃路径和脚本需要一次性迁移。
