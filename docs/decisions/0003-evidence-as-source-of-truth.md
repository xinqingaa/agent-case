# ADR-0003：详细版与证据台账共同构成项目事实源

状态：接受
日期：2026-08-19

## 背景

摘要、面试稿和旧说明容易脱离实现，独立维护多份事实会产生漂移。

## 决定

项目的重要事实必须存在于详细版并引用 `EVIDENCE.md`。简洁版、学习速记和面试材料只能从已验收详细版派生。

## 后果

- 详细版仍是学习事实源。读者定位用路径、模块或命令；证据编号由 Agent 维护在 `EVIDENCE.md`。
- 详细版验收成为派生产物的前置条件。
- 证据编号和跨文档一致性需要工具辅助维护。
- 后续见 [ADR-0004](0004-learner-surface-and-capabilities.md)：学习面不再把证据标记当作读者必修。
