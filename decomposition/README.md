# 项目学习拆解系统

本目录用于把 `code/` 下的完整项目转化为可验证、可学习、可复习的详细学习文档。

当前阶段只建设通用文档系统，不继续读取或拆解任何项目源码。项目分析必须在本体系通过审阅后，再按项目单独授权。

## 核心约定

1. 详细版是唯一事实源，简洁版只从通过验收的详细版派生。
2. 先讲用户和产品链路，再讲架构和代码。
3. README、旧文档、目录名和面试稿都不是实现事实。
4. 静态结论、运行结论、用户确认、推断和未知必须区分。
5. 默认不读取 `code/`；每个项目必须先完成授权卡。
6. 默认不修改原项目，不读取真实密钥和数据文件，不调用外部系统。
