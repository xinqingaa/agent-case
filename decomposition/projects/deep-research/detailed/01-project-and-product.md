# DeepResearch 项目与产品概览

## 阅读说明

- 阅读目标：理解项目为什么存在、服务谁以及实现了哪些真实能力
- 预计时间：15 分钟
- 验证状态：产品定位来自现有文档 `[I]`；交互能力和执行链路由源码验证 `[V]`

## 一句话定位

DeepResearch 是一个带 Web 工作台和 CLI 的研究助手：它把简单问题路由到快速回答，把复杂研究问题拆解后通过网络与本地知识检索、证据审计、分析和可选补搜，最终生成带来源列表的 Markdown 报告。[V][E-FLOW-004][E-FLOW-007]

“企业级”以及投资研究、竞品分析等目标场景来自现有产品说明，当前仓库没有需求文档、用户数据或部署证据证明其已经达到企业生产标准。[I][E-PROD-001][E-PROD-002]

## 它解决什么问题

| 问题 | 项目中的解决方式 | 当前证据 |
|---|---|---|
| 简单问题不值得走昂贵研究链路 | 规则初判 + LLM 复核后进入 direct 或 multiagent | `[V]` E-FLOW-005 |
| 复杂问题需要拆分 | Planner 生成子问题、大纲、预算和搜索计划 | `[V]` E-FLOW-005 |
| 单一来源覆盖不足 | Web 与本地 Milvus 两条检索分支 | `[V]` E-FLOW-004、E-FLOW-006 |
| LLM 可能编造来源 | 节点只保留真实输入 source ID，Writer 移除非法引用 ID | `[V]` E-FLOW-006、E-FLOW-007 |
| 证据不足时需要继续查找 | Analyst 标记缺口，Reflect 生成补搜计划并增加迭代 | `[V]` E-FLOW-004、E-FLOW-007 |
| 用户希望看到执行进度 | FastAPI 将图节点更新转换为 SSE，前端实时显示阶段 | `[V]` E-FLOW-001、E-FLOW-002、E-FLOW-003 |
| 多轮交互需要上下文 | 记忆管理器在执行前注入画像/摘要/相关记忆，执行后持久化本轮 | `[V]` E-DATA-002 |

## 目标用户与场景

现有说明将目标用户定义为行业研究员、投资分析师、技术架构师、产品经理和咨询顾问。[I][E-PROD-002]

源码实际提供的是通用研究输入框，没有角色权限或专门领域模型。因此更准确的当前边界是：任何能提交自然语言问题的用户都可以使用通用快速回答或研究报告流程。[V][E-FLOW-001][E-RISK-001]

## 当前可见入口

| 入口 | 用户行为 | 输出 | 状态 |
|---|---|---|---|
| Vue Web | 输入问题和 tenant/user/thread ID，提交研究 | 阶段进度 + 最终 Markdown | `[V]` E-FLOW-001 |
| 同步 HTTP API | POST `/api/v1/research/run` | JSON 中的最终文本 | `[V]` E-FLOW-002 |
| SSE HTTP API | POST `/api/v1/research/stream` | `status/phase/route/final/error` 事件 | `[V]` E-FLOW-002 |
| CLI | 单次问题或交互循环 | 终端打印最终文本 | `[V]` E-ARCH-007 |

## 核心能力边界

### 源码可以确认

- direct 与 multiagent 两条执行路径。
- 八个独立 LLM Agent 对象，Reflect 复用 Planner。
- Bocha Web 搜索与 Milvus 本地检索。
- 来源 ID 约束、证据池、审计标记和参考资料渲染。
- PostgreSQL、Redis、内存、SQLite、Milvus 的多级记忆/检查点选择与降级。
- FastAPI + SSE + Vue 的完整交互链路。

### 不能确认或不应声称

- “幻觉率降至 6%”“引用准确率 94%”等指标没有评测脚本或数据集证据。[U][E-OPEN-007]
- Neo4j、MySQL、MCP、WebSocket 不在当前实现调用链中。[V][E-ARCH-010]
- 没有认证、权限、限流和审计闭环，不能称为已具备企业多租户安全能力。[V][E-RISK-001][E-RISK-002]
- 尚未运行，不能确认当前提交能够安装、启动并完成一次真实研究。[U]

## 初学者先记住的三件事

1. 产品主线不是“八个 Agent”，而是“问题分流 → 证据生产 → 证据约束下的报告”。
2. Agent 只负责结构化推理；Web/RAG 检索由 Python 节点直接调用，Agent 没有绑定工具。[V][E-ARCH-009]
3. 当前最大差距不是提示词，而是运行可复现性、自动化测试、密钥治理和租户隔离。
