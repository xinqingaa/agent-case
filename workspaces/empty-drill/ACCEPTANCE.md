## 最终检查

### 事实与证据

- [ ] 非平凡结论能在台账中追溯，学习文档用路径、模块或命令定位。
- [ ] 声称已跑过的结论有真实运行记录。
- [ ] 用户确认和代码事实没有混淆。
- [ ] 推断与未知项被明确保留。

### 产品、架构与链路

- [ ] 产品链路能够映射到实现链路。
- [ ] 架构图节点能够映射到真实模块或外部系统。
- [ ] 至少一条核心链路端到端完整。
- [ ] 核心链路包含失败、重试或降级分析。
- [ ] `09` 讲业务能力和思路，而不是函数精读。

### 学习体验

- [ ] 有明确阅读顺序和前置知识，且符合默认读者画像。
- [ ] 没有把纯前端实现或拆解方法论写成必修。
- [ ] 关键术语已进入术语表。
- [ ] 练习偏向定位、协作和调试，包含完成标准和验证方法。
- [ ] 表达材料没有无依据指标或虚构贡献。

### 运行与安全

- [ ] 启动命令记录环境、前置条件和成功信号。
- [ ] 未写入真实密钥或个人数据。
- [ ] 有副作用操作已获授权并被记录。
- [ ] 原项目未发生未授权修改。
