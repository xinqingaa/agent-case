# Scripts

| 脚本 | 作用 |
|---|---|
| `init-project.sh` | 从模板创建原子化工作区，不读取源码 |
| `validate-project.sh` | 校验项目元数据、结构、占位符、阶段和证据引用 |
| `validate-project-yaml.rb` | 使用 Schema 的可移植 YAML 检查器 |
| `validate-skill.rb` | 校验仓库 Skill 的 frontmatter 和 UI 元数据 |
| `check-links.rb` | 检查 Markdown 本地链接 |
| `check-repository.sh` | 汇总仓库结构、旧路径、语法和链接检查 |

这些脚本只做机械检查，不授予权限，也不代替事实和学习质量评审。
