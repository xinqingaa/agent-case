# Templates

`project-decomposition/` 是 0.2 版项目工作区模板。模板结构必须与 [`docs/specifications/document-contract.md`](../docs/specifications/document-contract.md) 一致，并由 [`scripts/init-project.sh`](../scripts/init-project.sh) 复制到 `workspaces/<project-id>/`。

模板中的 `{{PLACEHOLDER}}` 必须在最终验收前全部解决；主题不适用时写明理由，不删除契约要求。
